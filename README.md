Entry for the [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun.

The task: send exactly one word — the single word your grandma would text about AI. This entry sends one original word: **SKYNET**. Grandma, typing in all caps, is convinced the AI is Skynet.

`main.ts` is a deterministic Node program (stdlib only, no dependencies). It writes the word to `<MAKEFUN_OUTPUT_DIR or /output>/entry.txt`, with a guard that the word is 1–30 characters long and contains no whitespace, and it reads the file back after writing to verify its contents are exactly the word. Running it twice produces byte-identical output.
